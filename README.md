# Catálogo de Productos y Favoritos — API REST + JWT + Frontend

API REST con Node.js/Express, PostgreSQL, autenticación JWT, autorización por roles y
frontend React + Vite con diseño *bento grid*. Proyecto académico con fines demostrativos.
